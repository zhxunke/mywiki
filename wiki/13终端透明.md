# Niri 透明终端配置（玻璃风格）

> 环境：Niri `26.04` / Arch Linux / 终端 kitty
> 风格：**无模糊 + 半透明**，窗口背后透出清晰的壁纸
> 配置日期：2026-10-25

---

## 一、效果说明

### 1.1 透明是怎么实现的

终端的透明效果由**两层**叠加而成，缺一不可：

```
        ┌───────────────────────────────┐
        │        终端窗口（kitty）       │  ← 第 2 层：终端画成半透明
        │   ┌───────────────────────┐   │
        │   │   文字、光标          │   │
        │   └───────────────────────┘   │
        ├───────────────────────────────┤
        │   窗口背后区域（清晰的壁纸）    │  ← 第 1 层：Niri 提供的背景
        └───────────────────────────────┘
                  桌面壁纸
```

| 层 | 负责者 | 配置文件 | 作用 |
|---|---|---|---|
| 第 1 层 | **Niri** | `~/.config/niri/blur.kdl` | 决定窗口背后画什么（本项目：不模糊，直接透出壁纸） |
| 第 2 层 | **终端** | `~/.config/kitty/kitty.conf` | 决定终端背景有多透明 |

- 只有 Niri 没有终端透明度 → 纯色窗口，看不到背后
- 只有终端透明度没有 Niri 配置 → 也能透出壁纸，但无法控制是否模糊

### 1.2 本方案的特点：无模糊

本项目选择**完全关闭背景模糊**：

| 项目 | 取值 | 效果 |
|---|---|---|
| 背景模糊 | **关闭** | 背后是**清晰锐利**的壁纸，不是柔化的色块 |
| 终端透明度 | **0.5** | 50% 的壁纸直接透进来 |

这叫"玻璃"，但与"磨砂玻璃"（带模糊）不同：

| 风格 | 模糊 | 观感 | 可读性 |
|---|---|---|---|
| 磨砂玻璃 | 开启 | 柔和、高级 | 好 |
| **本方案：清玻璃** | 关闭 | 通透、锐利 | **依赖壁纸** |

> ⚠️ **可读性提醒**：无模糊时，文字直接压在壁纸图案上。深色主题 + 亮色/高细节壁纸
> 的组合会明显影响阅读。若觉得吃力，把 `background_opacity` 调高（如 0.6~0.7）
> 或换一张暗色、低细节的壁纸。

## 二、配置原理

### 2.1 `blur { }` 参数块 ≠ 模糊开关

```kdl
blur {
    passes 3
    offset 3
    noise 0.02
    saturation 1.5
}
```

这个顶层块只定义**模糊的质感参数**，本身不产生任何效果。
真正决定"是否模糊"的是窗口规则里的 `background-effect { blur true/false }`。

**所以本方案保留 `blur { }` 块但不使用它**，将来想恢复模糊时把 `blur false` 改回 `blur true` 即可，参数已经就位。

> 注意：顶层 `blur{}` 在整个 niri 配置中**只能出现一次**。本项目仅在 `blur.kdl` 中定义，
> `cfg/misc.kdl` 里的旧 `blur{}` 已注释。

### 2.2 `xray` 是什么

`background-effect` 里还有一个 `xray` 选项：

| 取值 | 行为 |
|---|---|
| `xray true` | 只渲染一次背景并固定，不随下方窗口变化，**零性能开销** |
| `xray false` | 实时渲染窗口背后的内容 |

由于本项目已关闭模糊，`xray` 对视觉几乎没有影响，保留 `true` 以确保最低开销。
fuzzel 启动器用的是 `layer-rule`，设为 `xray false`（启动器自身要贴桌面，不做背景复用）。

### 2.3 窗口规则与 layer 规则

| 类型 | 适用对象 | 本项目案例 |
|---|---|---|
| `window-rule` | 普通应用窗口 | kitty、其他应用 |
| `layer-rule` | layer-shell 客户端（启动器、面板、通知） | fuzzel `^launcher$` |

两类规则互不通用，所以要分别写。

### 2.4 为什么要 `draw-border-with-background false`

Niri 的焦点环/边框默认会在窗口背后**绘制一层背景**。窗口半透明时，这层背景会在边框处露出一圈实色。

```kdl
window-rule {
    match app-id="^kitty$"
    draw-border-with-background false
}
```

关闭后，边框区域也跟随窗口透明。

### 2.5 焦点环与圆角

Niri 默认焦点环为 `width 4`、颜色 `#7fc8ff`，且**向外扩展**。它一直存在，本项目未覆盖。

圆角大小会明显影响它的观感：

| 圆角 | 焦点环表现 |
|---|---|
| `8` | 圆弧极短接近直角，4px 亮蓝环在拐角形成短促高光，**看起来像发光、刺眼** |
| `20` | 沿大圆弧走，转折柔和，像细描边 |

因此本项目使用 **`geometry-corner-radius 20`**。

三个放大"发光感"的因素：`draw-border-with-background false`（无暗色缓冲）、
终端半透明（暗底亮环对比高）、背景亮度不均。

> 若想改用小圆角，可同时调淡焦点环：
> ```kdl
> focus-ring {
>     width 2
>     active-color "#bec2ff80"   // Noctalia 主题 color2 + 50% alpha
> }
> ```
> 写进 `cfg/layout.kdl` 的 `layout { }` 块内。

## 三、完整配置

### 3.1 `~/.config/niri/blur.kdl`

```kdl
// --- NIRI GLASS START ---
// 玻璃风格：不做模糊，窗口背后是清晰的壁纸，由终端自身的半透明体现"玻璃"。
//
// 说明：blur{} 顶层块仍然保留（niri 的 blur 参数与是否启用是两件事），
// 但所有窗口规则都改为 blur false，因此不会有任何模糊被渲染。
// 若将来想恢复模糊，把下面对应的 blur false 改回 blur true 即可。
blur {
    passes 3          // 当前未启用（所有规则 blur false），保留作为备用参数
    offset 3
    noise 0.02
    saturation 1.5
}

// 全局窗口规则：普通窗口不做背景模糊
window-rule {
    background-effect {
        xray true
        blur false
    }
}

// 浮动窗口同样不做背景模糊（快速终端、剪贴板弹窗等属于这类）
window-rule {
    match is-floating=true
    background-effect {
        xray true
        blur false
    }
}

// fuzzel / 启动器 layer 规则：同样关闭模糊
layer-rule {
    match namespace="^launcher$"
    geometry-corner-radius 8
    background-effect {
        xray false
        blur false
    }
}

// 终端单独处理：避免边框背景盖在透明窗口上
window-rule {
    match app-id="^kitty$"
    draw-border-with-background false
}
// --- NIRI GLASS END ---
```

### 3.2 `~/.config/niri/config.kdl`

确保 include 列表里有这一行：

```kdl
include "./blur.kdl"
```

> 完整 include 列表（本机）：
> ```kdl
> include "./cfg/animation.kdl"
> include "./cfg/autostart.kdl"
> include "./cfg/keybinds.kdl"
> include "./cfg/input.kdl"
> include "./cfg/display.kdl"
> include "./cfg/layout.kdl"
> include "./cfg/rules.kdl"
> include "./cfg/misc.kdl"
> include "./blur.kdl"
> ```

### 3.3 `~/.config/niri/cfg/rules.kdl`

全局圆角设为 20：

```kdl
window-rule {
    geometry-corner-radius 20 // 圆角大会让焦点环过渡更柔和
    clip-to-geometry true
}
```

> ⚠️ 不要在这里再写 `background-effect`。窗口规则**按顺序匹配**，
> 没有 `match` 的规则会抢占所有窗口，导致 `blur.kdl` 里的规则失效。

### 3.4 `~/.config/niri/cfg/misc.kdl`

确认旧的 `blur{}` 块已被注释，避免重复定义：

```kdl
// blur{} 已移至 ~/.config/niri/blur.kdl 统一管理，避免重复定义导致配置报错
// blur {
//     passes 2 ...
// }
```

### 3.5 `~/.config/kitty/kitty.conf`

```conf
background_opacity 0.5
```

| 数值 | 效果 |
|---|---|
| `0.5`（当前） | 50% 透，通透感强，需要壁纸配合 |
| `0.6~0.7` | 更易读，玻璃感稍弱 |
| `0.85` | 仅隐约透出 |

可选增强，允许运行时用 `Ctrl+Shift+A` 再按 `M` 实时光调：

```conf
dynamic_background_opacity yes
```

## 四、生效方式

### 4.1 验证语法（必做）

```bash
niri validate
```

期望输出：

```
 INFO niri: config is valid
```

配置有误会**导致 niri 无法启动**，务必先验证。

### 4.2 应用配置

| 方式 | 操作 | 说明 |
|---|---|---|
| **完整重启（推荐）** | `systemctl --user restart niri` | 确保窗口规则彻底重建 |
| 退出重登 | `Mod+Shift+E` | 等同重启 |
| 自动热重载 | 保存文件即可 | 多数改动会生效，但规则顺序变化建议重启 |
| kitty 重载 | `Ctrl+Shift+F5` | 改了 `kitty.conf` 之后 |

### 4.3 验收

1. 新开一个终端：`Mod+T` 或 `Mod+return`
2. 观察背后是否**清晰地**透出壁纸（不是模糊色块）
3. 检查边框处没有突兀的实色矩形

## 五、故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 终端完全看不到背后 | `kitty.conf` 的 `background_opacity` 为 1 或被注释 | 设为 `0.5`，`Ctrl+Shift+F5` 重载 |
| 仍然有模糊 | 某条规则还是 `blur true` | `grep -n "blur true" ~/.config/niri/blur.kdl`，注意排除注释 |
| 有透明但边框一圈实色 | 缺 `draw-border-with-background false` | 检查 §3.1 末尾的 kitty 规则 |
| 改 `blur.kdl` 无效果 | `config.kdl` 缺 include，或被 `rules.kdl` 的前置规则抢占 | 检查 §3.2、§3.3 |
| niri 启动失败 | `blur{}` 重复定义，或版本 < 26.04 | `niri validate` 看行号 |
| 文字难以阅读 | 无模糊 + 透明度太低 + 壁纸太花 | 提高 `background_opacity` 或换暗色壁纸 |

## 六、参数调整速查

### 6.1 想更通透 / 更清晰

编辑 `~/.config/kitty/kitty.conf`：

| 目标 | 调整 |
|---|---|
| 更通透 | `background_opacity 0.45` |
| 更易读 | `background_opacity 0.65` |

改完 `Ctrl+Shift+F5`。

### 6.2 想恢复模糊（回到磨砂玻璃）

编辑 `~/.config/niri/blur.kdl`，把三处 `blur false` 改成 `blur true`：

```kdl
window-rule {
    background-effect {
        xray true
        blur true      // ← 改这里
    }
}
```

`blur { }` 里的参数立即生效，可按需微调：

| 目标 | 参数 |
|---|---|
| 模糊更强 | `passes 5` 或 `offset 5` |
| 性能优先 | `passes 2`、`offset 2` |
| 减少色带 | `noise 0.03~0.05` |
| 颜色更艳 | `saturation 1.5~2.0` |

### 6.3 想换焦点环颜色

在 `cfg/layout.kdl` 的 `layout { }` 内加：

```kdl
focus-ring {
    width 2
    active-color "#bec2ff80"
}
```

`#bec2ff` 是 kitty 主题的 `color2`。

## 七、关键要点

1. **透明需要两侧配合**：Niri 决定背景显示什么，终端决定透多少。
2. **`blur{}` 不是开关**：它只是参数，启停看 `background-effect { blur true/false }`。
3. **顶层 `blur{}` 全局唯一**：拆分配置时只能有一个文件定义。
4. **窗口规则顺序敏感**：无 `match` 的规则抢占所有窗口，`rules.kdl` 里不要放 `background-effect`。
5. **无模糊 = 可读性靠壁纸**：这是"清玻璃"风格的固有代价。
6. **改完先 `niri validate`**：配置错误会导致会话起不来。
7. **焦点环跟着圆角变**：圆角 8 显刺眼、20 更柔和。
8. **备份**：`blur.kdl.bak3`（玻璃改造前）、`kitty.conf.bak2`（透明度 0.5 版本）。
